# KBC Quiz Game Application

A Java Swing-based quiz game inspired by Kaun Banega Crorepati (KBC). The application provides an interactive quiz experience with multiple-choice questions, timer-based gameplay, score tracking, and lifelines.

## Features
- Multiple-choice quiz questions
- Countdown timer for each question
- Automatic score calculation
- 50:50 Lifeline
- Double Dip Lifeline
- Extra Time Lifeline
- Interactive GUI using Java Swing
- Result screen displaying final score

## Technologies Used
- Java
- Java Swing
- AWT
- Object-Oriented Programming (OOP)
